# Documentos do FundaIA

- `articles/`: biblioteca de artigos e referencias externas usadas na pesquisa.
- `contexto_academico/`: documentos internos do projeto, incluindo plano de trabalho, relatorio parcial e manuscritos em construcao baseados no FundaIA.
- `artigo_ic_lucas/`: artigo cientifico em construcao da IC do Lucas Teixeira Correia (estrutura LaTeX completa, conteudo parcial). Ver README dedicado dentro da pasta.

Para contexto acadêmico integrado ao vault, ver `obsidian_vault/01_Projeto/Contexto Acadêmico - IC Lucas e TCC Filipe Amaral.md`.
