# Biblioteca de artigos

Pasta reorganizada em 2026-04-27 para separar os PDFs por funcao dentro da pesquisa e facilitar leitura pelo vault/IA. Os arquivos abaixo foram preservados; a organizacao mudou apenas nomes de pastas e arquivos para tornar o acervo rastreavel.

## Estrutura

- `00_duplicados_exatos`: PDFs duplicados preservados apenas por rastreabilidade; nao usar como fonte canonica.
- `01_artigo_1_ego_gpr`: referencias centrais para fechar a etapa atual do projeto, com foco em EGO, GPR, Bayesian Optimization, otimizacao economica de sapatas isoladas e comparacao com metaheuristicas.
- `02_apoio_tecnico_geotecnia`: referencias tecnicas de engenharia/geotecnia que ajudam a validar o dominio de fundacoes.
- `03_apoio_metodos_aec`: referencias de apoio sobre metodos computacionais, metaheuristicas, automacao e contexto AEC.
- `04_futuro_packing_layout`: referencias para frentes futuras, incluindo layout/forma, confiabilidade, active learning e topicos que podem apoiar bin packing/layout.
- `05_frente_c_cbo`: fontes da Frente C (otimizacao bayesiana com restricoes): aquisicao ECI/PoF e variantes escalaveis.
- `06_novos_classificados/fora_escopo`: PDFs lidos e classificados como fora do recorte do artigo atual.
- `99_pendencias_ocr`: arquivo que nao deve ser tratado como fonte principal sem cuidado adicional, por OCR pendente.

## Leitura recomendada agora

Para a fase atual da IC, priorizar `01_artigo_1_ego_gpr` e usar `02_apoio_tecnico_geotecnia` como suporte tecnico. A pasta `04_futuro_packing_layout` fica registrada para a proxima frente, depois de validar e fechar o que ja foi construido no FundaIA.
